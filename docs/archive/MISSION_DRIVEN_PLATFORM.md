## 📚 Campaign Library: OSINT for Good

### Campaign Category 1: Human Trafficking Investigations

#### Campaign 1.1: "Operation Shadow Network"
**Difficulty**: Intermediate | **Time**: 60-90 min

**Scenario**: A trafficking ring is recruiting victims via Instagram. You've intercepted communications mentioning usernames and cryptocurrency wallets.

**Learning Objectives**:
- Social media OSINT (Instagram, TikTok, Snapchat)
- Behavioral pattern analysis
- Network mapping (victim-recruiter-customer)
- Cryptocurrency tracing (Bitcoin, Monero)
- Geolocation techniques
- Facial recognition (with consent/legal)

**Skills Taught**:
- Advanced search operators
- Image reverse search (TinEye, Google Images)
- Metadata extraction (ExifTool)
- Social graph analysis (Maltego, SpiderFoot)
- Blockchain analysis (Blockchain.com, Chainalysis)
- Report writing for law enforcement

**Ethical Guidelines**:
- Never contact suspects directly
- Never pretend to be a victim (illegal)
- Report findings to authorities, not vigilante action
- Protect victim privacy
- Follow legal constraints on data access

**Real-World Application**:
- Based on actual FBI case methodology
- Tools used by Thorn and NCMEC
- Taught by former investigators

#### Campaign 1.2: "Dark Web Marketplace Takedown"
**Difficulty**: Advanced | **Time**: 90-120 min

**Scenario**: A dark web marketplace is selling exploitation material. Map the infrastructure, identify operators, trace cryptocurrency payments.

**Learning Objectives**:
- Tor network investigation (safely)
- Dark web scraping techniques
- Cryptocurrency de-anonymization
- Server infrastructure mapping
- Opsec failures (finding real identity)
- Evidence preservation

**Tools**:
- Tor Browser (for safe research)
- OnionScan (dark web analysis)
- Blockchain explorers
- Server fingerprinting
- Cryptocurrency mixing detection

**Ethical Boundaries**:
- Never download illegal content
- Never make purchases
- Work only with sanitized data/metadata
- Always coordinate with law enforcement

#### Campaign 1.3: "Victim Identification Protocol"
**Difficulty**: Expert | **Time**: 120+ min

**Scenario**: Law enforcement has recovered images from a trafficking case. Help identify location and time period to narrow victim search.

**Learning Objectives**:
- Visual geolocation (architecture, landmarks, flora)
- Temporal analysis (weather, shadows, clothing)
- Cultural context (language, currency, brands)
- Image forensics (manipulation detection)
- Collaborative OSINT (crowd-sourcing)

**Real-World Impact**:
- Modeled after Project VIC methodology
- Used by Interpol and FBI
- Has led to real rescues

**Safety Protocols**:
- All imagery is anonymized/sanitized
- No direct viewing of exploitation material
- Focus on environmental clues only
- Psychological support resources provided

### Campaign Category 2: Financial Crime & Money Laundering

#### Campaign 2.1: "Follow the Crypto"
**Difficulty**: Intermediate | **Time**: 45-60 min

**Scenario**: $500k in Bitcoin from a ransomware attack has been linked to human trafficking. Trace it through mixers and exchanges.

**Learning Objectives**:

- Wallet clustering
- Cross-chain analysis
- Financial intelligence reporting

**Tools**:

**Real-World Application**:
