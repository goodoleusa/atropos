# OSINT Specialist Learning Path

## Target Audience

**For**: Aspiring OSINT analysts, private investigators, corporate intelligence professionals, journalists

**Prerequisites**: None - start from zero

**Time Commitment**: 60-80 hours self-paced

**Career Goal**: Professional open-source intelligence investigator

## Learning Objectives

By completing this path, you will be able to:

1. Conduct comprehensive passive reconnaissance without alerting targets
2. Correlate identities across multiple social media platforms
3. Geolocate images using satellite imagery and shadow analysis
4. Navigate dark web safely for intelligence gathering
5. Build professional investigation dossiers
6. Use industry-standard OSINT tools (Maltego, Shodan, etc.)
7. Apply multi-source intelligence fusion techniques
8. Maintain operational security during investigations
